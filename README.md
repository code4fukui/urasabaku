# urasabaku

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository contains 3D scans and related media of Urasabaku (裏砂漠), a volcanic desert on Izu Ōshima, Japan. The assets were captured on 2023-07-02. The 3D models were created with [Scaniverse](https://scaniverse.com).
