# urasabaku

このリポジトリには、日本の伊豆大島にある火山性砂漠「裏砂漠」の3Dスキャンおよび関連メディアが収録されています。各アセットは2023年7月2日に撮影・取得されました。3Dモデルは[Scaniverse](https://scaniverse.com)を使用して作成されています。

## アセット
